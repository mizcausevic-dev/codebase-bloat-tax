# Demo fixture (invented sample)

`ledger-desk-demo` is not a Kinetic Gain lockfile and is not installable.

`npm-lock.demo.json` is a **parser fixture**. Integrity strings are placeholders (`sha512-demo-…`). Do not run `npm install` in this directory. The filename is not `package-lock.json` so GitHub Dependabot does not treat this sample as the app's dependency tree.

Declared versions are patched relative to the 2026-09 Dependabot scan of the previous `package-lock.json` copy (lodash 4.18.1, vite 7.1.3).
