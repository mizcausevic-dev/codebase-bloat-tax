How an analysis is calculated

Decision support, not a blame score. Stronger evidence replaces weaker estimates. Nothing here proves payroll recovery.

Ingest

Local upload → Public GitHub URL → Private OAuth (server) → Snippet / OCR

Files stay in memory. Tokens are never stored. Screenshots are OCR’d in the browser.

Evidence hierarchy (strongest wins)

1
Real bundle artifact / source map / metafile → shipped module contribution
2
CI workflow timestamps → observed duration percentiles
3
Resolved lockfile → exact graph, duplicates, vuln input
4
Bundlephobia → advisory single-package min+gzip. Never summed as “your bundle”
5
package.json or import screenshot → declared / candidate directs only

Pure models

transferTimeMs = compressedBytes / effectiveThroughputBytesPerMs + RTT

annualBlockingHours = runs/week × weeks/year × blockingMinutes/run × affectedDevelopers / 60

potentialTimeValue = annualBlockingHours × hourlyCost

Gzip is never labeled uncompressed. Build-wait estimated mode is a clamped hypothesis, not observed latency. Opportunity cost is potential time value under selected assumptions.

Outputs

Labeled report → PR markdown (top 3) → Warning-first workflow preview
